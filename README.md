# Ostenna

A community and marketplace app for home and coffee goods enthusiasts: discussion forums, marketplace listings, and user profiles in one Next.js app.

## Features

- Email auth with login and registration flows
- Forums organized by category, with threaded discussions
- Marketplace listings with per-item detail pages
- Public user profiles

## Tech

Next.js (App Router), TypeScript, Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view it locally.
